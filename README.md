# Vivek Koundal ? Portfolio

A cinematic personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS. Scroll through an animated Tokyo skyline while the portfolio scenes transition in sync with the video.

## Features

- Scroll-scrubbed video background and a final skyline reveal
- Animated introduction, About, featured projects, skills, and contact scenes
- Responsive design with reduced-motion support
- Profile photo, GitHub and LinkedIn links
- Project source repositories and live demos

## Technology

- Next.js 14 App Router
- React 18 and TypeScript
- Tailwind CSS 3
- Lucide React icons
